## bioSite: Robyn's Story

A three-page profile about Robyn's martial arts practice, community, and continued growth. The site uses a shared stylesheet, the visual system planned in Module 5.2, and the selected photos from that planning packet.

### Pages

- `index.html` — landing page and training milestones
- `about.html` — biography and portrait
- `hobbies.html` — karate, taekwondo, and current training goals

Open `index.html` in a browser to view the site.
